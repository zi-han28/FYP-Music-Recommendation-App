# FYP-Music-Recommendation-App

Music has always had a profound emotional value as it is an integral part of everybody’s life. In the modern context, the majority would get their music from music streaming platforms and discover music through their respective music recommendation system.  Personally, when I first started using these music streaming platforms, I was consistently underwhelmed by the recommended songs, which were usually the popular, general choices that did not align with my personal tastes. This limits peronalised discovery and ignores the emotional value that music holds for people. Furthermore, these streaming platforms often over rely on personal listening history or playlists for their recommendation system, which is a form of surveillance that raises privacy issues. Therefore, the project I am taking is project 7.2: NextTrack: A music recommendation API.

The core motivation of this project is to address these limitations mentioned above, by developing a Music Recommendation System that delivers advanced personalisation without compromising user privacy. This project will mainly focus on data and algorithmic techniques to accurately map lyrical themes and audio characteristics to personal preferences. This approach would cater to both new and veteran users, by providing instant, accurate recommendations while also maintaining discovery and personalisation.
